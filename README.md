# Matrix Operations in C

A C program that implements and tests several matrix operations, including matrix transposition, matrix multiplication, matrix comparison, identity matrix creation, orthogonal matrix creation, and Gaussian elimination.

## Overview

This project was developed independently as part of my computer science coursework. The program uses dynamically allocated matrices and separate functions to create, manipulate, test, and display matrix data.

## Features

- Dynamic matrix allocation
- Matrix transposition
- Matrix multiplication
- Matrix comparison
- Identity matrix creation
- Orthogonal matrix creation
- Gaussian elimination
- Matrix input and output
- Testing of matrix operations

## Technologies

- C
- GCC
- Standard C libraries

## What I Learned

This project provided hands-on experience with C programming, dynamic memory allocation, functions, nested loops, mathematical algorithms, and debugging. It also gave me experience implementing mathematical operations from the ground up and testing the results of those operations.
